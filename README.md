# GitHub Commit을 활용한 알고리즘 스터디 인증 수단 commity
<img width="829" height="609" alt="1444" src="https://github.com/user-attachments/assets/d80e2176-48a0-4280-ae97-11823a95948b" />



## 프로젝트 소개
- 진행 중인 알고리즘 팀스터디에서 매주 문제를 풀었다는 인증 수단이 필요하여 개발
- GitHub Webhook과 REST API를 활용해 커밋을 기반으로 한 인증 서비스를 제공
- Server-Sent Events를 활용한 유저별 커밋 수 조회 실시간 업데이트
- 매주 스터디 진행 후 완료 버튼 클릭 시 포인트 적립
- 일정 포인트 미달 시 자동 탈락

## 개발 환경
- 프로그래밍 언어: Java 17
- 웹 프레임워크: Spring Boot 3.4.3
- 데이터베이스: MySQL
- ORM: JPA
- 클라우드 서비스: AWS(EC2, RDS)
- API: GitHub Webhook/REST API
- 템플릿 엔진: Thymeleaf
